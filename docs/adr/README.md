# ADR 目录（架构决策 + 模块详细规格）

本目录记录局域网象棋 MVP 的架构决策与各功能入口的详细规格（spec）。
每篇 ADR 统一包含：背景 → 决策 → 详细规格 → 代码入口 → 验收标准。

| 编号 | 标题 | 覆盖模块 / 功能入口 |

## 阅读路径建议

- 想跑起来：先看 [../README.md 快速开始](../README.md#2-快速开始)。
- 想改规则/裁判：[0002](./0002-rules-engine.md) → [0008](./0008-testing-strategy.md)。
- 想改联机/消息：[0010](./0010-room-server.md)（**当前架构**）→ [0003](./0003-wire-protocol.md) → [0004](./0004-game-state-machine.md) → [0005](./0005-host-server.md)（历史）。
- 想改界面/交互：[0007](./0007-renderer-ui.md)。
- 想改启动方式/构建：[0006](./0006-process-entries.md)。
- 想改棋谱/AI/观战/计时/自动发现：[0009](./0009-c-d-extensions.md)。
- 想了解架构演进：[0001](./0001-host-authoritative-architecture.md)（主机权威，部分被取代）→ [0010](./0010-room-server.md)。

> 说明：0001 / 0003 / 0005 / 0006 记录的是**主机权威时代**的决策与规格，其中与服务器形态、
> 协议入口、进程入口相关的部分已被 [0010](./0010-room-server.md) 取代（各篇开头已标注）；
> 规则引擎（0002）、状态机（0004）、渲染层（0007）、测试策略（0008）与 C/D 档扩展（0009）仍然有效。
