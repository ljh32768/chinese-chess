## 1. 概述

本方案基于《局域网象棋 MVP 产品设计文档》和现有 HTML Demo，确定局域网两人中国象棋的技术实现路线。

核心原则：

- **主机权威**：主机维护唯一真实棋盘状态，负责规则校验和胜负判定。
- **加入者请求**：加入者只发送走子意图，由主机判定。
- **规则引擎与 UI 分离**：规则引擎为纯 TypeScript 模块，不依赖 DOM 和网络。
- **简单同步**：每步广播完整棋盘，带 `seq` 防乱序。
- **桌面优先，兼顾浏览器加入**：主机端使用 Electron，加入者可以是 Electron 客户端，也可以是浏览器。

---

## 2. MVP 范围

### 2.1 包含

- 创建对局、加入对局
- 主机显示本机 IP 和端口
- 9×10 棋盘、棋子显示、选中、合法落点、上一步高亮
- 完整中国象棋走子规则、将军、应将、将死、困毙
- 认输、和棋、重开、离开
- 主机权威同步、走子请求、合法性校验、广播棋盘、`seq` 防乱序
- 断线提示、程序不崩溃

### 2.2 不包含

- 账号、公网联机、匹配服务器
- 排行榜、战绩、AI、观战、回放
- 多房间、大厅、房间号、密码
- 自动发现、断线重连、悔棋、计时
- 长将、长捉、重复局面等复杂裁判规则

## 3. 总体架构

采用 **主机权威 + WebSocket 通信 + 纯 TS 规则引擎** 架构。
